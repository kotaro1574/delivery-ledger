# 稼ぐ手応えダッシュボード（レベル＋月間目標）設計

## 目的
収入を入力するたびに「稼いでる」「育ってる」と実感でき、もっと配達しようと思える台帳にする。帳簿としての正確さ（青色申告用の数字）は崩さない。

## ゴール
- 累計売上で上がるレベルと経験値バーを台帳トップに常時表示する
- 月ごとの売上目標を設定でき、達成率と「残り日数で割った1日あたりペース」が見える
- 収入を保存した直後に、増えた金額とレベルアップをお祝い表示する

## ノンゴール
- バッジ・実績・ランキング・連続記録（ストリーク）などの追加ゲーム要素
- 年次ページの変更
- 利益ベースの目標

## アンチゴール
- 経費・利益など帳簿の数字が見づらくなること
- 目標が端末やブラウザの都合で消えること
- 派手すぎて毎日開くのが鬱陶しくなること（アニメは保存直後の1回だけ）

## 検討したアプローチ
1. **台帳トップにステータス領域＋目標を D1 保存（採用）** 毎日開く画面でご褒美が見え、目標が端末をまたいで残る。マイグレーションと API 追加が必要。
2. 同じ見た目で目標は localStorage。手軽だが PWA でデータが消えると目標も消える。
3. 別タブ「ステータス」ページ。帳簿は静かに保てるが、毎日見る画面にご褒美が出ないので目的に逆行。

ユーザーが 1 を選択。

## 決定事項（ユーザー）
- レベルは **累計売上**（全期間の revenue 合計）で決まり、下がらない
- 目標は月ごとに D1 に保存
- 目標は売上ベース（Claude の提案、ユーザーは異議なし）

## 設計

### レベル曲線（Claude の判断）
Lv n → n+1 に必要な売上 = `30,000 + 5,000 × (n − 1)` 円。Lv1 スタート、上限なし。
- Lv10 到達: 累計 ¥450,000 / Lv20: ¥1,425,000 / Lv30: ¥2,900,000
- 序盤は月に数回、慣れてきたら月1回程度上がるペース
- 称号を 10 レベル刻みで付ける：ルーキー(1–9) → レギュラー(10–19) → エース(20–29) → ベテラン(30–39) → レジェンド(40+)
- 純粋関数 `levelFromRevenue(total)` → `{ level, title, currentLevelStart, nextLevelAt, progress }` をユニットテスト付きで実装

### データ
- 新テーブル `monthly_goals(user_id, month 'YYYY-MM', target_amount INTEGER > 0)`、`(user_id, month)` で unique。マイグレーション `0002_monthly_goals.sql` と drizzle schema に追加
- 累計売上は既存の revenue 集計クエリから月条件を外したもの

### API（Hono, summary / goals モジュールの既存パターンに合わせる）
- `SummaryService.monthly` のレスポンスに `lifetimeRevenue` と `goal: number | null` を追加
- `PUT /api/goals/:month` `{ targetAmount }` で upsert、`DELETE /api/goals/:month` で解除

### 台帳トップ（既存の売上/経費/利益カードの上に追加）
```
┌──────────────────────────────────────────┐
│ Lv.12  レギュラー            累計 ¥612,400 │
│ ███████████████░░░░░  次のLvまで ¥8,400    │
├──────────────────────────────────────────┤
│ 11月の目標 ¥300,000   ✎                    │
│  (◔ 62%)  ¥186,000 稼いだ                  │
│           あと ¥114,000 ・ 1日 ¥19,000 ペース │
└──────────────────────────────────────────┘
```
- 目標未設定の月は「今月の目標を決めよう」ボタン。✎ で金額入力のポップオーバー
- 1日ペースは表示中の月が今月のときだけ（残り日数 = 今日を含む月末まで）。過去月は「達成 / 未達」だけ表示
- 達成したら 100% で色が変わり「目標達成！」表示。超過分も「+¥12,000 オーバー」で見せる
- 色は既存の紙・ベージュ基調を維持し、ゲーム要素だけにアクセント色（金系）を 1 色追加

### 保存直後のお祝い（Claude の判断）
- 入力画面で収入を保存したら `/?gained=<金額>` へ遷移
- 台帳はそのパラメータがあるとき、上部にバナー「+¥12,000 ゲット！」を出し、`lifetimeRevenue − gained` と `lifetimeRevenue` のレベルを比較してレベルが上がっていれば「LEVEL UP! Lv.11 → Lv.12」を表示
- 経験値バーは保存前の位置から伸びるアニメーション（1 回だけ、`prefers-reduced-motion` では無効）
- 閉じると `router.replace` でパラメータを消す。経費保存時は今まで通り

## 制約
- 既存スタック：Next.js App Router / Hono / Drizzle / D1 / Tailwind v4 / shadcn
- `any` 禁止、説明コメントなし、`useEffect` は極力避ける
- 既存のテスト（vitest）を壊さない。レベル計算・ペース計算・目標 API にテストを足す

## ビルダーに任せること
- コンポーネント分割、ファイル配置、アニメーションの具体的な実装
- 目標入力ポップオーバーの細かい UI
