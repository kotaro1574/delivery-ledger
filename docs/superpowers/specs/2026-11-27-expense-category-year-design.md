# 経費を勘定科目ごとに 1 年分見る 設計

## 目的と理由

経費には車両費・通信費などの種類（勘定科目）があるが、絞り込む手段がない。

- ねんかん画面は科目ごとの年間合計だけ
- だいちょう画面の明細は 1 か月単位

そのため「2026 年の車両費を 1 件ずつ確認したい」と思ったら、12 か月分をめくって目で探すしかない。ユーザーの要望は「車両費などの経費を全部見られるようにしたい」。見せ方はおまかせされたので、明細と月ごとの増え方の両方を 1 画面で見られるようにする。

## ゴール

- 年と科目を選ぶと、その年のその科目の経費が全件見られる
- 合計（事業分・支払額）と月ごとの合計も一緒に見られる
- 明細からそのまま修正・削除できる（だいちょうと同じ操作）

## やらないこと

- 収入の絞り込み、複数科目の同時選択、期間の自由指定、CSV 出力
- データ構造や DB の変更

## 決めたこと（ユーザー承認済み）

- **新しいページ** `/year/expenses?year=2026&category=601`
  - タイトルは「{年}年の けいひ」
  - 中身は上から次の順
    - 年の切り替え（◀ ▶）
    - 科目の切り替え（6 科目のボタン）
    - 合計（事業分、その下に支払額）
    - 「つきごと」の棒グラフ（1〜12 月）
    - 「めいさい（N けん）」の一覧（新しい順）
  - 明細は日付・メモ・金額・按分（私用分があるとき）・レシートの有無を出し、なおす / けすができる
- **入り口**：ねんかん画面の「年間経費内訳（事業分）」の各行をタップすると、その年・その科目でこのページを開く
- **やめた案**
  - 年間ページの中で開閉する方式：ページが長くなりすぎる
  - だいちょうの明細に絞り込みを付ける方式：1 か月単位のままで、要望に合わない

## 作りの方針（実装者の判断）

- 取得はサーバーコンポーネントからサービスを直接呼ぶ（既存のページと同じ）。HTTP の API は増やさない
  - 承認時の説明では「API を 1 つ追加」と言ったが、既存ページの作りに合わせる
- `EntriesService.listExpenses(userId, year, categoryCode)` を足す。明細を組み立てる処理は、月の一覧 `list` と共通にする
- だいちょうの「まいにちの とりひき」（一覧＋なおす / けすのダイアログ）を部品 `EntryLedger` に切り出して、新しいページでも使う
- コマンドメニューは `/year/expenses` でも「ねんかん」を選択中にする
- 文言はひらがなのゲーム口調。科目名（車両費など）・事業分・私用分は漢字のまま
- 不正な `year` は今年に、不正な `category` は車両費（601）にする

## 確認方法

- vitest / tsc / Biome が通る
- 375px 幅で次を確認する
  - ねんかん画面からの移動
  - 年と科目の切り替え
  - 明細のなおす / けす
