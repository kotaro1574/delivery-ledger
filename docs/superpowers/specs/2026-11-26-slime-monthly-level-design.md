# 配達員スライム × 月間目標レベル 設計

## 目的
生活費として毎月稼がないといけない額（月間目標）に対して、今月どこまで来たかをゲームの成長として実感できるようにする。累計売上は使ったお金も含むので、生活の手応えとしては意味が薄い（ユーザーの判断）。

## 決定事項（ユーザー）
- キャラは萌え要素なしのスライム。配達員スライムが装備と乗り物を増やし、最後はキング化
- レベルは月間目標の達成率で決める（毎月 Lv1 から）
- 1 レベルごとに少しずつ見た目が変わる

## 検討したアプローチ
- キャラ: A 配達員スライム＋キング化（採用） / B モンスター育成型（配達との接点が薄い、キング要素だけ採用） / 画像生成（クレジット消費・レベル単位の制御が難しく見送り）
- レベル基準: 達成率 2.5% ごとに 1Lv（採用） / 達成月数（月 1 回しか上がらない） / 累計売上＋達成ボーナス（ユーザーの意図と合わない）

## レベル計算（Claude の判断）
- `level = floor(revenue * 40 / goal) + 1`。0% で Lv1、100% で Lv41
- 段階 `tier = min(4, floor((level - 1) / 10))`、称号 ルーキー / レギュラー / エース / ベテラン / キング
- 段階内ステップ `step = tier < 4 ? (level - 1) % 10 : 9`（キングは全装備）
- 王冠の宝石 `gems = tier === 4 ? min(3, floor((level - 41) / 4)) : 0`（目標超過 10% ごとに 1 つ）
- 次の Lv までの額 `ceil(level * goal / 40) - revenue`
- 目標未設定の月はレベルなし（たまご表示）

## スライムのドット絵（Claude の判断）
- 32×32 マスをコードで描画（SVG rect、行ごとにランレングス結合、`shape-rendering="crispEdges"`）。画像ファイルなし
- オリジナルの「おもち型」スライム（有名作品のしずく型には寄せない）
- 段階ごとの乗り物と体色: 徒歩/みどり → 自転車/みずいろ → 電動アシスト＋スピード線/むらさき → 原付/オレンジ → バイク＋王冠＋マント/ゴールド
- ステップで累積的に装備追加: 1 ほっぺ / 2 ヘルメットの星 / 3 スカーフ / 4 バッグのワッペン / 5 ゴーグル / 6 キラキラ1 / 7 キラキラ2 / 8 スカーフがなびく / 9 オーラ
- 待機中はぷるぷる（`motion-safe` のみ）

## 画面
- ステータス欄を 1 枚に統合: スライム / Lv・称号 / 達成率バー（目標に対する %）/ 稼いだ額・目標額 / あと◯円・1 日ペース / 次の Lv まで / 目標編集 / 👑 キング達成回数
- 累計売上の表示と経験値バー、目標リングは削除
- 目標未設定: たまご＋「目標を決めるとスライムが生まれる」＋目標設定ボタン
- 過去月はその月の最終形を表示（ペースなし）

## データ / API
- `SummaryModel.Response`: `lifetimeRevenue` を削除し `kingMonths: number`（目標を設定し売上が目標以上だった月の数、全期間）を追加
- 目標 API は変更なし

## お祝い表示
- 収入保存後 `/?month=<収入の月>&gained=<金額>` に遷移
- その月の `revenue - gained` と `revenue` で Lv を比較。段階が変わったら「◯◯に進化！」、Lv41 到達で「目標達成！スライムキング誕生！」
- `gained` はその月の売上以下の正の整数のみ有効。目標未設定なら金額だけ表示
